## 明确不允许

- 自己实现权限判断 —— 调用 2.3 的 `can()`
- 自己铸 token —— 调用 7.2 的接口
- 麦克风、设备、音量（那是 3.2）
- 屏幕共享（那是 4.1）

## Validation

```bash
pytest tests/voice -v
npm run test -- voice
# 真机验证：两台不同网络的电脑，一台国内一台德国
```

## 完成标准 —— 这是 R01 的纵切片关卡

```
Electron 启动 → 输入昵称 → 取 token → 加入房间
→ 看见成员 → 开麦 → 另一台真实电脑听见 → 静音 → 退出
```

- [ ] **上面这条链路在中德两台真机之间跑通**
- [ ] 点击频道进入对应 LiveKit 房间
- [ ] 成员列表显示当前参与者
- [ ] 麦克风默认关闭
- [ ] **重复点击不会创建重复连接**
- [ ] 连接失败时显示可理解的错误，不是白屏

## 非目标（R01 不做）

- 自动重连 → R02
- 摄像头 → 3.3 / R03
- 屏幕共享 → 4.1

## 备注

**这条链路跑通之前，任何 UI 模块都不应开工。** 它同时验证四个最贵的未知：
token 契约、LiveKit 配置、跨境网络、客户端打包。
