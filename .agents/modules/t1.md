## 职责与契约

- 原有领域归属沿用父规格的职责列：6.1 准入页，6.2 UI 原语/令牌/中文翻译，2.2 认证 provider，2.3 真实 `can(user, action, channel)`，7.2 准入签发与限流。新启动与共享契约由 T1 的 Jack 签认；既有模块的完整 Release 验收仍各自有效。
- 最小 UI 为一页准入表单、Button、TextInput、状态/错误反馈、设计令牌和中文 `t()` 入口；共享 UI 不调用业务 API。不在本片扩展侧栏、成员列表或完整主题系统。
- 准入响应、token claims 与权限动作各保留一份权威 schema，TypeScript 与 Python 消费同一份契约。接口或数据模型变化先由 Jack 裁决并同步契约，不能另建枚举或字段副本。
- 普通入口只接受真实认证/授权 provider，缺少 provider 时拒绝启动；独立回环测试启动器注入测试身份、批准房间与运行期随机秘密。普通入口不导入或回退到 fixture，fixture 不进入分发包；测试仍通过真实路由、校验、`can()`、限流和签名。
- T1 内存限流仅用于单服务进程、单 worker；启动参数要求单 worker。额度、原子扣额、时间边界与错误顺序沿用父规格，不能宣称多进程或生产防滥用已完成。
- 昵称、凭据有效期、能力、错误响应与 Electron 信任边界以父规格为权威；T1 只准备准入，不建立媒体连接、采集媒体或申请媒体权限。

## 明确拒绝

本清单不包含任何迁移（含正式 `versions/` 与 `_proposed/`）、ORM/数据库变化、`.env`、生产配置、基础设施或现有测量实验。也不包含表外源码、完整账号系统、其他切片或全局契约变更；既有迁移提议流程不因此获得 T1 授权。

运行产物按已有忽略规则处理，不提交依赖目录、专用环境、构建输出或秘密。证据遵守只追加规则；原有实验与其他工作副本保持原样。

## Validation

范围检查从仓库根运行，使用实际修改列表：

```bash
git diff --name-only --no-renames -z origin/main...HEAD | node .agents/scope_guard.mjs t1
```

边界自测：第一个命令须退出 0；其余三个须退出 1。完整 44 文件的允许验证和表外拒绝验证见 #3 的 docs PR 实际输出，不能把这些 harness 检查当作产品运行证据。

```bash
node .agents/scope_guard.mjs t1 --files package.json packages/contracts/admission.schema.json tests/tokens/test_admission_http.py
node .agents/scope_guard.mjs t1 --files apps/desktop/src/shell/Sidebar.tsx
node .agents/scope_guard.mjs t1 --files apps/api/migrations/versions/0001_init.py
node .agents/scope_guard.mjs t1 --files apps/api/migrations/_proposed/t1.sql
```

按实施 Issue 运行对应入口；T1 最终验收必须包含以下全部产品检查。尚未提供或执行的入口明确记录 `NOT_RUN`，不能据此宣布 T1 完成。

仓库根的桌面入口（包含共享 UI 与契约）：

```bash
npm run typecheck --workspace apps/desktop
npm run lint --workspace apps/desktop
npm run test --workspace apps/desktop
npm run build --workspace apps/desktop
npm run package:win --workspace apps/desktop
npm run test:e2e --workspace apps/desktop
```

在 `apps/api` 的独立 uv 环境运行：

```bash
uv run python -m ruff check app ../../tests/conftest.py ../../tests/tokens ../../tests/ratelimit
uv run python -m ruff format --check app ../../tests/conftest.py ../../tests/tokens ../../tests/ratelimit
uv run python -m pytest ../../tests/tokens ../../tests/ratelimit -v
```

T1 无 ORM、数据库或迁移变化，`alembic check` 记录为 `NOT_APPLICABLE` 并说明原因，不写成 `PASS`；其他模块的数据库验证要求保持原样。任何持久化需求先回到独立范围和契约审查。
