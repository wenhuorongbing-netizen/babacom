## 完成标准

**R01：**
- [ ] 颜色 / 字体 / 间距令牌定义完成并冻结
- [ ] 共享原语：button、modal、list、avatar
- [ ] 亮/暗主题
- [ ] **i18n 框架就位，中文文案完整**

**R03：** 英文文案完整校对 · 字号控制

**R04：** 每用户强调色

## 为什么它必须最早开工

**它不依赖任何模块，却阻塞所有 UI 模块。** 和 1.1 一起属于 wave 0。

**双语必须 day-one 做框架**（`scope.html` 这一点是对的）：
事后往几十个组件里补 i18n，比一开始就用 `t()` 包起来贵得多。
但**文案本身可以先只有中文**，英文校对放 R03 —— 这样既不返工也不拖进度。

## 契约地位

设计令牌与组件库是七个冻结契约之一。
**其他模块提议新增组件，不自行在功能目录里造一个按钮。**
