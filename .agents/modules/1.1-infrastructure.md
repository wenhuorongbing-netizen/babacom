## Validation

```bash
docker compose -f infra/compose.yaml config          # 配置语法
docker compose -f infra/compose.yaml up -d --wait    # 起得来
curl -fsS https://app.<域名>/healthz                  # TLS + 路由通
```

## 完成标准

- [ ] 两个节点都能一条命令拉起
- [ ] TLS 证书自动续期已验证（不是「配了应该行」）
- [ ] Postgres 每日备份已跑通，**且做过一次恢复演练**
- [ ] SSH 仅密钥登录，密码登录已关
- [ ] `.env.example` 列全所有必需变量，无真实值
