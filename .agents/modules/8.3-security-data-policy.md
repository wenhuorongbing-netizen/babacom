## 完成标准

- [ ] 容器镜像按摘要固定，不用 `:latest`
- [ ] 依赖扫描接入 CI，高危阻断合并
- [ ] 密钥轮换流程写进手册并演练一次
- [ ] 日志留存 ≤ 14 天，附件 90 天自动清理
- [ ] **一份平实语言的风险说明**：这是自托管服务、跨境流量的现实情况是什么、
      我们存了什么、没存什么、留多久

## 指导原则

> **没有存的东西，不会泄露，也不会被要求交出。**

不收集身份证件、手机号、真实姓名。无消息内容分析、无录音、无第三方遥测。
这不只是隐私姿态 —— 它同时把攻击面和运营责任压到最小。

无公开注册这一条本身就消除了垃圾用户、滥用和内容治理三整类问题。
