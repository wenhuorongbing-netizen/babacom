## 完成标准

**R01：**
- [ ] 发送 / 编辑 / 删除自己的消息
- [ ] 管理员删除他人消息（通过 `can()`，不自己判断）
- [ ] 回复某条消息
- [ ] @user
- [ ] 基础 Markdown（粗体 / 斜体 / 剧透 / 代码块）
- [ ] **游标分页历史**（不是 offset 分页，消息会插入）
- [ ] 未读位置

**R03：** 反应 · @role / @everyone

**R04：** 自定义表情 · 斜杠命令 · 投票
