## 范围

按T2规格固定媒体执行域、准入所有权、默认闭麦、显式采集、
唯一Room与取消/退出清理。先验证实际开发/打包产物的本地真实入房和合成订阅；
随后最小非fixture provider，最后有设备同意条件的双设备听音。

本清单是拟签认产品路径的上界；不是本轮文档任务的Allowed Files。
实施必须先等Jack批准书面规格及具体docs边界PR，不因清单在分支存在而获得权限。
每张实现票逐个声明实际需要的更小子集；发现表外必要修改先停并走独立docs范围PR。

## 明确不允许

- 在T2-C文档PR中夹带任何产品、schema或依赖修改；T2-C使用Module: docs。
- 修改T1规格、t1清单、现有三份schema或正常T1测试；需要另提明确契约/测试任务。
- 重做AuthenticationProvider、AuthorizationProvider或PermissionPolicy.can。
- feature互相import；媒体/音频端口在preload组合，UI组件在renderer组合。
- API secret进入客户端；应用会话离开main；JWT/Room/通用IPC进入UI主世界。
- 未经明确契约签认采用preload持有媒体JWT或SDK信令URL例外。
- 关闭contextIsolation、sandbox、webSecurity；打开nodeIntegration、任意网络或采集。
- 把同frame的上下文隔离宣传为设备权限隔离；默认采集、预热或枚举设备。
- 生产fixture回退；真实会话只改标签；静音冒充设备释放；本地合成传输冒充人耳或跨境。
- 共享、摄像头、自动重连、原生SDK、数据库/迁移、完整2.2/2.3或别的模块UI。
- 改既定昵称、120秒初始媒体TTL、grants、限流、Alpha指标。
- 操作任何infra源文件或现有韩国服务器，采购/部署/联系朋友/未同意物理采集。
- 扩此清单或修改治理文件放进功能PR；这些变更使用独立Module: docs。

## Validation

每票从以下既有入口按其适用性执行；新增测试须已接线且输出证明确实运行。
客户端票保持T1应用回归，不能用未发现voice/audio测试的全绿命令签收。

```powershell
npm run typecheck --workspace apps/desktop
npm run lint --workspace apps/desktop
npm run test --workspace apps/desktop
npm run build --workspace apps/desktop
npm run package:win --workspace apps/desktop
npm run test:e2e --workspace apps/desktop
```

T2-02建立并接线新目录后，在apps/api运行：

```powershell
uv run python -m ruff check app ../../tests/conftest.py ../../tests/tokens ../../tests/ratelimit ../../tests/accounts ../../tests/permissions
uv run python -m ruff format --check app ../../tests/conftest.py ../../tests/tokens ../../tests/ratelimit ../../tests/accounts ../../tests/permissions
uv run python -m pytest ../../tests/tokens ../../tests/ratelimit ../../tests/accounts ../../tests/permissions -v
```

```powershell
node .agents/scope_guard.mjs t2 --files <本票实际文件>
```

T2-C只运行docs边界、guard测试及规格内文档一致性断言；
本清单的产品检查当前NOT_RUN。DB无变更时说明NOT_APPLICABLE，不能写alembic PASS。
真实SFU/合成peer、设备和跨境实验的命令、资源与通过条件在对应Issue固定后执行。
既有本地SFU缓存只是线索，复用前核验官方版本/校验值；缺资源不暗中安装或换版本。

      播放激活与旧事件清理通过；两台Windows两主体有实际人耳记录。

      20分钟/每方向19/20/正常入房9/10暂定项目指标与限流排程如规格。
- [ ] 每PR有实际命令/退出码及NOT_RUN/HOLD边界；自动化、合成媒体、
      真人听音和跨境分别记录，Alpha10语音/1共享/9观看/至少2小时不因T2通过而完成。
