每张实现票逐个声明实际需要的更小子集；发现表外必要修改先停并走独立docs范围PR。

## 明确不允许

- 在T2-C3文档PR中夹带任何产品、测试、schema或依赖修改；本轮使用Module: docs。
- 修改T1规格、t1清单、现有三份schema或除上述狭窄例外之外的T1测试；其他必要变更仍须另提明确契约/测试任务。
- 重做AuthenticationProvider、AuthorizationProvider或PermissionPolicy.can。
- feature互相import；媒体/音频端口在preload组合，UI组件在renderer组合。
- API secret进入客户端；应用会话离开main；JWT/Room/通用IPC进入UI主世界。
- 真实JWT进入信令URL或可序列化错误/日志（包含Chromium原生网络诊断）；撤销PR15的URL例外。初始JWT只留main并经批准媒体请求头传输；SFU刷新token可留专用隔离媒体域，不得进入UI、URL或持久化。
- 关闭contextIsolation、sandbox、webSecurity；打开nodeIntegration、任意网络或采集。
- 业务UI frame承载SDK或借用媒体认证头；默认采集、预热、准备阶段/媒体上下文销毁后的枚举。仅当前媒体上下文生存期内允许SDK被动枚举，仍不申请采集权限或主动枚举，不向UI传设备清单。
- 生产fixture回退；真实会话只改标签；静音冒充设备释放；本地合成传输冒充人耳或跨境。
- 屏幕共享、摄像头、自动重连、原生SDK、数据库/迁移、完整2.2/2.3或别的模块UI；通用成员列表原语只接收稳定键和展示内容，不依赖媒体schema。
- 改既定昵称、120秒初始媒体TTL、grants、限流、Alpha指标。
- 操作任何infra源文件或现有韩国服务器，采购/部署/联系朋友/未同意物理采集。
- 扩此清单或修改治理文件放进功能PR；这些变更使用独立Module: docs。
