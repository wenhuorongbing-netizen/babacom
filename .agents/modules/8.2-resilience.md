## 完成标准

- [ ] 每日备份 + 异地副本
- [ ] **做过至少一次真实恢复演练** —— 未演练的备份视为不存在
- [ ] RPO ≤ 24 小时，RTO ≤ 4 小时
- [ ] 备用 IP 和备用域名已就位，客户端能切换端点
- [ ] 事故手册覆盖：IP 被墙、证书过期、磁盘满、数据库挂、流量超额
- [ ] 状态页可从国内访问

## 为什么备用 IP 必须提前准备

**一个被封的 IP 疏通可能需要数周。** 预案必须在事发之前就存在 ——
事发之后再开始找备用 IP，意味着这几周里产品完全不可用，
而这足以让所有人退回 Discord 并且不再回来。
