## 明确不允许

- 权限判定逻辑 —— 那是 2.3 的 `can()` 原语，本模块只管「你是谁」不管「你能干什么」
- 两步验证（已在 Won't 列）

## Validation

```bash
pytest tests/accounts -v
```

## 完成标准

- [ ] 密码用 argon2 或 bcrypt 哈希，**不是** sha256
- [ ] 会话可被管理员单独撤销（踢下线）
- [ ] 移除成员后其所有会话立即失效
- [ ] 登录接口限流
- [ ] 头像上传有大小与类型校验

## 备注

**移除成员和撤销会话是 `plan01.md` 指出的缺口** —— 原 84 项功能表里没有，
但没有它们无法运营一个私人服务器。

密码找回依赖 **D3（邮件能否进 QQ/163 收件箱）**，未解决前的兜底方案是
管理员手动重置 —— 25 人规模完全可行，不要因为 D3 卡住整个模块。
