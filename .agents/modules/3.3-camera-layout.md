## 明确不允许

- 背景虚化（Won't 列）
- 自己写按钮 / 磁贴样式 —— 用 6.2 的组件库

## Validation

```bash
npm run test -- camera
```

## 完成标准

- [ ] 摄像头开关不影响麦克风状态
- [ ] 设备选择在多摄像头机器上正确
- [ ] 宫格 / 演讲者视图切换不丢流
- [ ] 关闭摄像头后**真的停止采集**（摄像头灯灭）

## 为什么后移到 R03

摄像头增加布局、设备和带宽复杂度，而这个群体的核心需求是**屏幕共享不是露脸**。
它和「大家能不能一起稳定打游戏」没有直接关系。见 `docs/01-scope-v2.md`。
