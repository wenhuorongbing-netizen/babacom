## 明确不允许

- 修改 `packages/contracts/token-claims.*` 而不走 Tech Lead
- 发放长期有效或不限房间的令牌 —— **任何情况下都不行**

## Validation

```bash
pytest tests/tokens tests/ratelimit -v
```

## 完成标准

- [ ] 令牌 TTL 短（分钟级），过期后必须重新申请
- [ ] claims 精确到房间 + 能力（publish / subscribe / screenshare / moderator）
- [ ] **令牌接口本身有限流**
- [ ] 未登录请求一律拒绝
- [ ] 权限判定调用 2.3 的 `can()`，不自己实现

## 这是安全关键模块

> **一个未限流的令牌接口只是把开放中继问题换了个位置，而不是解决它。**

任何人只要能无限申请令牌，就能把你的媒体服务器当成免费中继用。
这个模块的 review 必须由 Tech Lead 亲自做，不能只靠 CI。
