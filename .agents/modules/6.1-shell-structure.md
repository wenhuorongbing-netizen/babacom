## 范围

应用布局与侧边栏 · 多个文字频道 · 频道分类 · 频道主题行 · 置顶消息 ·
按角色分组的成员列表 · 键盘快捷键 · 移动端响应式 · 路由

## 明确不允许

- 定义新的颜色、字号、间距 —— **全部来自 6.2 的设计令牌**
- 各功能模块的内部实现

## Validation

```bash
npm run test -- shell
npm run typecheck
```

## 完成标准

- [ ] 多个文字频道 + 语音频道并列
- [ ] 频道分类可折叠
- [ ] 成员列表按角色分组
- [ ] 键盘快捷键不与全局快捷键（3.2）冲突
- [ ] **没有一个硬编码的颜色值或像素间距**

## 备注

本模块阻塞所有 UI 模块，所以它的接口（插槽、路由、布局约定）
一旦确定就要稳定下来。中途改外壳等于让所有 UI 模块返工。
