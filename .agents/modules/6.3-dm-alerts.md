## 明确不允许

- 好友列表与好友请求、拉黑、提及音效（全在 Won't 列 —— **社区邀请已足够覆盖固定朋友群**）
- 自定义状态文本（Won't 列）

## Validation

```bash
pytest tests/dm tests/notifications -v
```

## 完成标准

- [ ] 未读模型对普通频道和私信一致
- [ ] 桌面通知在客户端最小化到托盘时仍能触发
- [ ] 每频道通知级别独立生效
- [ ] presence 的语音状态与文字状态**是同一套**（7.1 负责协调）

## 备注

R01 只需要 **online / offline** 两态。
完整 presence（idle / DND / invisible）留在本模块的 R03 范围。

未读模型是 5.3 线程的前置依赖 —— **本模块的数据模型决定线程好不好做**，
设计时把线程当作未来的一个「频道子集」来考虑，但不要现在实现它。
