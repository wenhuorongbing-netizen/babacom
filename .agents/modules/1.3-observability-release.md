
## 完成标准

- [ ] 控制面 + 两个媒体节点都有健康检查端点
- [ ] 指标含：在线人数、房间数、出站带宽、丢包率、CPU
- [ ] **流量配额监控，达到 80% 告警**（限速套餐会在游戏夜当中静默触顶）
- [ ] staging 与生产同构，可独立部署
- [ ] 发布回滚跑通过一次

## 备注

流量为什么是主要监控对象，见 `docs/03-cost-model.md`。
