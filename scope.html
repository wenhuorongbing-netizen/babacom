Babacom Build Scope

A self-hosted Discord replacement for a 25-person group split between mainland China and Europe. Two servers, invite-only, no ID uploads, no per-seat fees. This is everything you ticked, everything you skipped, and what the total actually costs to build.

13–16Weeks, solo

The number worth arguing with: 13–16 weeks

I earlier estimated 2–4 weeks for a custom client. That was for a minimal one — voice channels and a screen share. This scope is roughly four times that, and the estimate has to move with it.

The four features carrying most of the extra weight are threads, message search, roles with per-channel permissions, and direct messages plus group DMs. Each is a week or more on its own, and threads touch the data model, the unread system and the notification system all at once. None of them are needed to start playing games together.

The build order at the bottom cuts this into three releases, the first of which is usable in about four weeks.

Two things still open

  • Mute/deafen hotkeys. You want them, but a browser tab can't see your keyboard while you're in a fullscreen game — which is exactly when you need them. A Chrome extension can register genuinely global shortcuts; a small tray app also works and covers Firefox; or hotkeys only fire when the tab is focused. Undecided.
  • Who can create invites. You picked both "admin-generated only" and "any member can invite." Recorded as a setting, defaulting to admin-only.

Build order

3 releases

Sequenced so the network risk is settled before any UI work, and so you're playing together by week five.

00

Prove the network first

Stock LiveKit on a rented box, a real person in China and one in Europe, measured at 21:00 Beijing during an actual game stream. This decides the host, the region topology and every bitrate default. Writing UI before this number exists is building on a guess.

1 week · no app code
01

Playable

Invites and login, voice channels with the full control set, screen sharing with resolution and framerate choice, basic text chat, region labels and connection indicators. At this point it replaces Discord for game nights, which is the actual goal.

≈ 4 weeks
02

Liveable

Attachments and media, channel categories and pins, reactions and replies, roles with per-channel permissions, notification settings, direct and group messages, both themes, bilingual interface.

≈ 6 weeks
03

Complete

Threads, message search, mobile layout polish, custom emoji, and the optional extras — slash commands and polls — if they still seem worth it by then. Several may not.

≈ 5 weeks
