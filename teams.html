The thing that decides whether this works

Eighteen teams editing one React app and one database will produce merge chaos, not parallelism. The modules below are cut along ownership seams — each owns its own routes, its own tables, and its own folder — but that only holds if the shared surfaces are settled first.

So the coordinator's real job is not assigning work. It is owning the seven contracts in the next section, and refusing to let any team change them unilaterally. Everything else is genuinely parallel.

Start order

4 waves

Not all 24 can start at once — six modules gate the rest. Domain numbers are labels, not order: 7.1 and 8.1 start in wave 0.

Wave 0

The five that block everyone

Infrastructure, the design system and the realtime gateway have no dependencies and block nearly everything else. Media operations runs the China measurement in parallel, since its result changes bitrate defaults everyone builds against — and hosting picks the box that measurement runs on.
