# Domain Docs

## Layout

single-context：仓库根 CONTEXT.md 与 docs/adr/。

## Reading

先遵守仓库 REPO_MAP.md、AGENTS.md 和目录规则。
术语、规格或架构探索时，若 CONTEXT.md 存在则读取，
并读取与任务相关的 ADR。

这些资料不存在时直接继续，不预建空文件。
术语或决策实际明确后，再由 domain-modeling 按任务需要补充。

## Vocabulary and decisions

采用领域文档已定义的术语；发现真实术语缺口时明确提出。
与已有 ADR 冲突时报告冲突，不默默覆盖已有决策。
