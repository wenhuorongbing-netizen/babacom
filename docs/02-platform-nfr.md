# 平台能力矩阵 · 非功能需求 · 验收负载

> 补 `scope.html` 缺失的三块内容。这三块决定「做完了」是什么意思。

## 1. 平台能力矩阵

写死每个平台支持什么，避免「网页版为什么不能分享游戏声音」被反复提问。

| 能力 | Windows 客户端 | 桌面浏览器（访客） | 手机浏览器 |
|---|---|---|---|
| 加入语音频道 | ✅ | ✅ | ✅ |
| 收听 / 观看共享 | ✅ | ✅ | ✅ 只读 |
| 发起屏幕共享 | ✅ 窗口 / 整屏 | ⚠️ 仅标签页或整屏，无游戏音频 | ❌ |
| 共享 **系统音频** | ✅ loopback 捕获 | ⚠️ 仅「分享标签页」且用户勾选音频 | ❌ |
| 全局静音/闭音快捷键 | ✅ | ❌ 仅标签页聚焦时 | ❌ |
| 托盘常驻 / 长期挂频道 | ✅ | ❌ 关标签即断 | ❌ |
| 桌面通知 | ✅ | ⚠️ 需授权 | ❌ |
| 自动更新 | ✅ | 刷新即最新 | 刷新即最新 |
| 输入/输出设备选择 | ✅ | ✅ | ⚠️ 受系统限制 |
| 文字聊天 | ✅ | ✅ | ✅ |

**读法：** 新人先用浏览器体验（不需要信任一个陌生的 GitHub EXE），愿意长期用了再装客户端。
这同时解决了群里那个正确的问题——「新人凭什么装一个不认识的 exe」。

## 2. 验收负载（Alpha）

不是最终上限，是**第一版验收时必须扛住的负载**。

| 维度 | 数值 |
|---|---|
| 注册成员 | 25 |
| 社区数 | 1 |
| 峰值同时语音 | 10 人 |
| 同时屏幕共享 | 1 路 |
| 共享观看者 | ≤ 9 |
| 主要平台 | Windows 11 x64 |
| 访客入口 | Chrome / Edge 桌面版 |
| 连续使用时长 | ≥ 2 小时不掉线 |

超过这些数字的性能问题**不算 Alpha 缺陷**，记入 backlog。

## 3. 非功能需求

### 3.1 音视频质量

| 指标 | 目标 | 不合格 |
|---|---|---|
| 语音单向延迟（同区域） | < 150 ms | > 300 ms |
| 语音单向延迟（中↔欧跨境） | < 300 ms | > 500 ms |
| 语音可用丢包上限 | 15%（Opus RED + inband FEC） | — |
| 视频可用丢包上限 | **6%** | 超过即无解 |
| 共享画面卡顿 | 每 10 分钟 ≤ 1 次可察觉卡顿 | — |

> **视频这条是硬边界。** 目前没有任何 WebRTC 媒体服务器实现了可用的视频前向纠错；
> 持续丢包超过约 6% 时，视频质量由网络路径决定，软件调参无法挽救。
> 因此**线路质量是承重决策，不是调优细节**——这也是 R00 必须先于一切的原因。
> 音频不同：Opus 加冗余和 inband FEC 在 15–22% 丢包下仍可用。**所以设计是音频优先，视频显式可选。**

### 3.2 可靠性

| 指标 | 目标 |
|---|---|
| 网络抖动后自动重连 | ≤ 10 秒内恢复或明确报错 |
| 笔记本睡眠唤醒后 | 自动重新入房，不需要重启客户端 |
| 音频设备热插拔（USB/蓝牙） | 自动切换或提示，不崩溃 |
| 服务可用性目标 | 尽力而为，无 SLA（私人服务） |
| 计划内维护 | 提前在文字频道公告 |

### 3.3 数据与备份

| 指标 | 目标 |
|---|---|
| Postgres 备份频率 | 每日 |
| RPO（可接受数据丢失） | 24 小时 |
| RTO（恢复时间目标） | 4 小时 |
| **恢复演练** | 每季度一次，未演练的备份视为不存在 |
| 日志留存 | 14 天 |
| 附件留存 | 90 天后自动清理（磁盘有限） |

### 3.4 安全与数据最小化

- 无公开注册；只有管理员生成的邀请码
- 不收集身份证件、手机号、真实姓名
- 密码使用 argon2 / bcrypt 哈希
- 令牌短时效、按房间限定作用域（publish / subscribe / screenshare / moderator）
- 令牌接口必须限流 —— **未限流的令牌接口只是把开放中继问题换了个位置，而不是解决它**
- 无消息内容分析、无录音、无遥测上报第三方
- 密钥不入库不入仓；`.gitignore` 已覆盖，另加 CI 密钥扫描
- 面向中国大陆用户提供一份**平实语言的风险说明**（自托管服务、跨境流量的现实情况）

> 原则：**没有存的东西，不会泄露，也不会被要求交出。**

### 3.5 可运维性

- 健康检查端点：控制面 + 两个媒体节点
- 指标：在线人数、房间数、出站带宽、丢包率、CPU
- **流量配额监控，达到 80% 告警** —— 限速套餐会在游戏夜当中静默触顶
- 备用 IP 与备用域名常备（IP 被墙后疏通可能需要数周，预案必须在事发前就存在）
- 事故手册 + 状态页
